# Malindi Marine Boat Excursions

Stunning single-page site for a dhow excursion business in Malindi Marine Park, Kenya. Snorkeling adventures and full-day island getaways with beach BBQ.

Built with vanilla HTML/CSS/JS: scroll-driven storytelling, parallax chapters, sticky booking CTA, Playfair Display editorial type.
